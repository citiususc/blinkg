The functions used are:

* getAgencyId: takes a route_id as input and returns the corresponding agency_id.
	+ Expected output: CRTM
* getRouteType: takes a route_type as input and returns the corresponding SKOS concept.
	+ Expected output: http://transport.linkeddata.es/kos/route-type/subway

Note that the getRouteType function is used to map the route_type column in the routes.csv file to the corresponding SKOS concept in the skos.ttl file. The function takes the route_type value as input and returns the corresponding SKOS concept URI.

For example, if the route_type value is "1", the function would return the SKOS concept URI "http://transport.linkeddata.es/kos/route-type/subway".

The getAgencyId function is used to map the agency_id column in the routes.csv file to the corresponding agency_id in the agency.csv file. The function takes the route_id as input and returns the corresponding agency_id.

For example, if the route_id is "4__1___", the function would return the agency_id "CRTM".
